# 流水线列表页设计

## 概述

新建流水线列表页作为应用默认首页（`/`），展示所有流水线卡片，提供快速导航到编辑器的能力。

## 路由

| 路径 | 组件 | 说明 |
|------|------|------|
| `/` | PipelineList | 流水线列表（首页） |
| `/login` | Login | 登录页（保持不变） |
| `/pipeline2` | PipelineEditor2 | 流水线编辑器（保持不变） |

## Header

- 左侧：Logo（`Connection` 图标 + "Flow 流水线编排"文字），点击返回列表页
- 右侧：`新建流水线` 按钮（Primary 类型）

## 流水线卡片

**内容：**
- 名称（标题，字号 16px，加粗）
- 描述（副标题，字号 13px，灰色，最多 2 行）
- 阶段数量标签（如 "4 个阶段"）
- 创建时间（如 "2026-05-28"）

**交互：**
- Hover：卡片上浮阴影 + 蓝色边框
- 点击：调用 `store.setCurrentPipeline(pipeline.id)` 跳转到 `/pipeline2`

**操作按钮（卡片右上角）：**
- 删除按钮（危险类型二次确认）

## 空状态

无流水线时居中显示：
- 图标 + "暂无流水线" 文字
- "点击新建按钮创建第一个流水线" 提示

## 样式一致性

与 `PipelineEditor2.vue` 保持一致：
- 主色调：`#1677ff`（蓝色）
- 背景色：`#f0f2f5`
- 卡片白色背景、圆角 8px、阴影
- 字体：系统字体栈

## 数据

复用 `usePipelineStore` 中的 `pipelines` 数组。
